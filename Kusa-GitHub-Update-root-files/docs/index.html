Get started in a minute

The phone workspace needs internet to open the first time. After installing, its app shell can be available offline; the laptop AI has a separate setup.

01 · PHONE

Open Kusa

Tap “Open phone workspace.” On iPhone use Safari; on Android use Chrome.

02 · PHONE

Add to Home Screen

Use the browser’s Share or menu option to install Kusa like an app.

03 · LAPTOP AI

Install Ollama separately

For offline Ask Kusa, install Ollama and download the selected model on the laptop once.
